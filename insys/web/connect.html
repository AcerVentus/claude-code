Set this device up, once

InSys encrypts everything it sends across the office network, so nobody else on the network can read it. For that, each device installs the InSys certificate one time. It takes about a minute, and this device will not ask again.

These are the steps for a device that is using InSys over the office network for the first time. Each device does this once.

  1. Download the certificate

    Download the InSys certificate

    It is not a program and it is not secret. It can only vouch for addresses on a private network such as this office's, never for a public website.

  2. Install it on this device

    Windows – Chrome, Edge, Firefox
    1. Open the downloaded file InSys-certificate.crt. If Windows asks, choose Open.
    2. Click Install Certificate…, leave Current User selected and click Next.
    3. Choose Place all certificates in the following store, click Browse…, pick Trusted Root Certification Authorities, then OK, Next and Finish.
    4. Windows shows a security warning that names InSys local certificate. Click Yes.
    5. Close the browser completely and open it again.
    Android phone or tablet – Chrome
    1. After the download, open the phone's Settings and search for CA certificate. (It is under Security, in More security settings or Encryption & credentials, then Install a certificate.)
    2. Tap CA certificate, then Install anyway, and confirm with your screen lock.
    3. Choose InSys-certificate.crt from Downloads.

    Android afterwards shows its standard notice that a certificate is installed. This one can only be used for private network addresses.

    iPhone or iPad – Safari
    1. After tapping Download, tap Allow. The iPhone says a profile was downloaded.
    2. Open Settings, tap Profile Downloaded near the top, then Install (enter your passcode) and Install again.
    3. Still in Settings, go to General › About › Certificate Trust Settings and switch on InSys local certificate.
    Mac – Safari, Chrome
    1. Open the downloaded file. Keychain Access opens; if it asks which keychain, choose login.
    2. In Keychain Access, find InSys local certificate and double-click it.
    3. Open Trust, set When using this certificate to Always Trust, close the window and enter your password.
    4. Quit the browser and open it again.
    Firefox, if it still shows a warning
    1. Open the Firefox menu, then Settings › Privacy & Security, scroll to Certificates and click View Certificates…
    2. On the Authorities tab click Import… and choose InSys-certificate.crt.
    3. Tick Trust this CA to identify websites and click OK.
    Linux – Chrome, Chromium
    1. Open Settings › Privacy and security › Security › Manage certificates.
    2. Under Authorities (or Custom › Trusted Certificates) click Import and choose InSys-certificate.crt.
    3. Tick Trust this certificate for identifying websites, confirm, and restart the browser.

    To be sure the file is the genuine one, compare the thumbprint your device shows while installing it with the one your administrator sees in InSys under Admin, System.

  3. Open InSys

    I have installed it – open InSys

    This device does not trust the certificate yet. Check the steps above, and close and reopen the browser if you have not done so.

    On a device you will only use once you can open the encrypted address without installing. The connection is still encrypted, but the browser shows a warning page first, every time.

    Once InSys opens, bookmark that page: its address starts with https.
